## 3. 判定方法

- Aは正規化した英語タグ名の完全一致。
- Bは既存タグの`aliases`との正規化一致。
- C/Dは、既存名との語の重なりを機械的な補助信号として使い、用途差があり得るものを独立候補として残した。意味の最終判断はレビューが必要。
- 大文字小文字、前後空白、Danbooru形式の`_`と空白、サイト上の括弧エスケープを正規化した。
- モデル互換性・生成品質は実生成で検証していない。

## 4. 出力ファイル

- `addition_candidates.csv`: A/Bを除いた高・中・低の候補。
- `duplicates_and_exclusions.csv`: A/Bの一致・エイリアス候補。
- `addition_candidates.json`: 既存カタログスキーマとは分離したレビュー用メタデータ。
- `category_proposals.md`: 新分類提案。今回は自動仮配置で既存分類に収まらない候補がなかったため、承認なしの新分類提案はない。

## 5. 制限・未確認

- サイトが公開HTMLに表示していない有料・ログイン限定・アクセス制限範囲は対象外。
- 説明文は公開カードの記載がある場合だけ転記し、ない場合は独自説明を補っていない。
- C/D/Eの意味判定、分類の最終妥当性、Stable Diffusion / Illustrious / NoobAI / Pony各モデルでの効果は未検証。
- `data/tag_catalog.json`本体は承認後に307件を反映済み。アプリコード、live install、GitHub、Registryは変更・同期していない。
